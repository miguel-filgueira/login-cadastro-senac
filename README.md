# 🔐 Sistema de Login e Cadastro Interativo

Aplicação web desenvolvida para praticar a criação de formulários interativos, validação de dados com JavaScript e conceitos de experiência do utilizador (UX/UI).

---

## 🚀 Tecnologias Utilizadas
- **HTML5** (Estrutura semântica dos formulários e inputs)
- **CSS3** (Estilização, layout flexível e transições visuais)
- **JavaScript** (Validação de campos, lógica de alternância e manipulação do DOM)

---

## 📌 Funcionalidades
- [x] Interface moderna para formulários de Login e Cadastro.
- [x] Alternância dinâmica entre a tela de login e a tela de registo.
- [x] Validação de campos obrigatórios (como e-mail e palavra-passe) via JavaScript.
- [x] Design responsivo adaptado para dispositivos móveis e computadores.

---

## 🎯 O que eu pratiquei neste projeto?
Este projeto permitiu aprofundar conhecimentos práticos em:
1. **Manipulação do DOM:** Leitura de valores inseridos nos inputs e exibição de mensagens de alerta ou erro.
2. **Eventos de Formulário:** Tratamento de eventos de submissão (`submit`) para evitar o recarregamento automático da página.
3. **Estrutura de Validação:** Lógica em JavaScript para verificar o preenchimento correto dos dados antes do envio.
